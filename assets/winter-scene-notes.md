# Winter scene variants

The three winter landscape variants were made with the built-in image-generation tool in `lighting-weather` edit mode. Each original desktop landscape was used as the edit target.

Shared prompt intent: transform the exact scene into a quiet, photorealistic winter version with natural snow across the mountain, vegetation, banks, and shoreline while keeping the lake liquid. Preserve the camera position, mountain silhouette, horizon, lake geometry, dimensions, composition, and major features. Add no people, text, animals, buildings, new objects, altered geography, storm, or frozen lake.

- `fuji-lake-winter-desktop.jpg` and `fuji-lake-winter-mobile.jpg`
- `yotei-lake-winter-desktop.jpg` and `yotei-lake-winter-mobile.jpg`
- `alps-lake-winter-desktop.jpg` and `alps-lake-winter-mobile.jpg`

The project JPEGs are performance-optimized derivatives. The original generated PNGs remain in the Codex generated-images directory.
