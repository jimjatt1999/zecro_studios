Word Hacker

iOS

Crack the code. Find the words.

Cyberpunk word puzzle game. Crack codes by finding hidden words using rotating dials. Earn points, unlock levels, customize your interface.

Core Features:

  • Dial-based Gameplay: Rotate two dials to align letters and find valid words.
  • Category System: Multiple word categories with increasing difficulty levels.
  • Department Organization: Categories grouped into logical departments.
  • Progress System: Unlock new levels as you complete challenges.
  • Breaker Points (BP): Earn BP for finding words, spend to skip or reveal targets.
  • Visual Effects: Matrix-style falling characters, terminal effects, signal bars.
  • Theme Selection: Multiple color themes for customization.
  • Immersive Audio: Sound effects enhance the hacking experience.
  • Story Elements: Mission briefings and narrative context for each level.
  • First-time Tutorial: Interactive instructions for new players.
  • Reveal Feature: Spend BP to access a target word list.
  • Japanese Language Category: Learn Japanese words while playing.
  • Dynamic Splash Screen: Matrix-style launch screen.
  • Enhanced Terminal Interface: Full cyberpunk aesthetic.
  • Speed Streaks & Bonuses: Find words quickly for BP multipliers.
  • In-App Help: Reopen the tutorial anytime by typing "help".

Planned Features:

  • Additional word categories
  • More language categories
  • More challenging gameplay modes
  • Enhanced story elements
  • Achievements system
